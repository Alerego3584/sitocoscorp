Collaborator logos for the Worked with marquee on About.

1. Put each logo file in this folder (SVG, PNG, WebP, or JPG).
   Transparent backgrounds look best on the dark site.

2. List the filenames in manifest.json, in the order they should slide:

   [
     "ja-italy.svg",
     "fenles.png",
     "ups.svg"
   ]

The marquee stays hidden until that list has at least one file.
